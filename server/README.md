# Server

Basic standalone Node.js server setup.

## Folder Structure

```
server/
├── package.json
├── .env.example
├── .gitignore
└── src/
    ├── index.js
    ├── config/
    ├── controllers/
    ├── middlewares/
    ├── models/
    ├── routes/
    ├── services/
    └── utils/
```

## Getting Started

```bash
npm install
npm run dev
```
